# 参考分析

来源：用户提供的「claude_剪视频过程motion」，Motionface 片段 ID `e3ee409a-50f7-4b4a-af27-288226e47a57`。

下载后使用 ffprobe 检查：1280×720，30 fps，H.264，AAC，时长 30.058 秒。用每 2 秒一帧的接触表分析全片，并检查 10 秒与 28 秒原尺寸画面。

## 画面语言

米白纸面（约 #f6f3e9），棕黑轮廓（约 #302c29），珊瑚色方块角色，淡绿按钮与预览背景，紫色音轨，黄色活动标签。线条有轻微手绘不规则感；中文字体接近楷体与手写标题。本实现使用开源霞鹜文楷替代原片字体。

软件界面占满画面：顶端文件名、时间码和导出按钮；左边素材/转场/文字面板；中央竖屏手机；右边调节滑块；底部多轨时间线。视频素材包含星月城市、拉面、柴犬和舞厅角色。素材缩略图重复排列在时间线上。

## 主要时间段

| 时间 | 原片主要事件 | 实现方式 |
| --- | --- | --- |
| 0–2 s | 界面绘出、选择夜景素材 | 边框与面板出现，角色伸手 |
| 2–6 s | 拼接素材与音轨 | 顺序出现的片段与波形 |
| 6–11 s | 放大转场操作、翻页 | 摄像机推近、长手臂、SVG 翻页 |
| 11–15 s | 添加文字、修正和撤销 | 文本轨、预览字幕、已修正印章与 Ctrl+Z |
| 15–20 s | 放大滑块，调饱和度与抖动 | 参数插值和角色指向滑块 |
| 20–23 s | 舞厅画面与节奏标记 | 角色摆动、灯光、时间线标记 |
| 23–26 s | 导出进度 | 导出按钮百分比和镜头回移 |
| 26–30 s | 背景淡出，Opus 5.5 收尾 | 半透明纸面、手机、卡片与彩屑 |

转场主要依靠界面镜头推拉、预览内容切换和动画操作，而不是大量整屏交叉淡化。角色的手臂是贯穿事件的叙事元素。原音轨保留，使近似重建仍按原片整体节奏播放。

## 重建边界

素材插画与角色使用可编辑的 SVG 重绘，未嵌入参考视频画面。各元素位置、手绘细节、翻页形状、粒子和音轨波形为近似；波形是确定性的可视图案，不代表原音轨逐采样幅度。镜头与事件依据关键帧分析进行分段还原。
